A collection of AI skills for Web3 operational security - built for use through AI agents.

## Why

Web3 teams need security guidance at the moment they're working, not buried in a doc they'll never open. These skills bring W3OS and SEAL framework knowledge directly into your AI assistant - so the right opsec guidance shows up exactly when it's needed.

## Skills

| Skill | Description |
|-------|-------------|
| [endpoint-threat-hunt](./endpoint-threat-hunt/) | Live threat hunting on macOS, Linux, and Windows using native OS tools only. Runs checks across 8 phases and produces a structured findings report. |
| [w3os-compass](./w3os-compass/) | Web3 opsec triage. Researches an org from public sources, maps gaps to W3OS and SEAL standards, surfaces top 5 priorities, and recommends matching W3OSC tools. |

## Usage

Copy the skill folder(s) into your AI assistant's skills directory and reference them in your agent configuration.

Or just give them this repo url for download.
